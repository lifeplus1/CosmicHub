# Demo Components Documentation

This directory contains demonstration components that showcase specific features and capabilities of CosmicHub.

## Available Demos

### FlowerOfLifeDemo.tsx
- **Purpose**: Demonstrates sacred geometry visualization capabilities
- **Features**: Interactive Flower of Life pattern with customization options
- **Usage**: Educational and demonstration purposes

### SacredGeometryDemo.tsx  
- **Purpose**: Showcases advanced geometric pattern rendering
- **Features**: Various sacred geometry patterns and animations
- **Usage**: Visual demonstrations and educational content

## Usage Guidelines

These components are primarily for:
- Documentation examples
- Educational demonstrations  
- Feature showcases
- Development references

## Integration Notes

To use these demos in the main application:
